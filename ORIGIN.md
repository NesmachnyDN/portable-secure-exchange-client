# Origin and publication boundary

This repository is an independent portfolio implementation of a general enterprise integration problem previously explored in a discontinued R&D prototype.

The public implementation is written from the architectural requirements and problem statement, not copied from the historical source tree. It does not contain historical organization names, package names, internal hostnames, database content, certificates, credentials, proprietary dictionaries, vendor crypto libraries, wrapper binaries or source-control history.

Architecture, requirements, deployment constraints and acceptance criteria are human-directed. AI-assisted development tools were used for parts of the implementation, testing and documentation under human architecture ownership and review.
